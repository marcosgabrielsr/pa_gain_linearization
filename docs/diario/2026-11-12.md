## Como acessar o Jupyter remoto

```bash
# 1) PC do orientador (dentro do tmux, para não morrer se a conexão cair)
ssh aluno_marcos_IC@guilherme-Xeon
tmux new -s jupyter
source ~/venvs/dpd/bin/activate && cd ~/pa_gain_linearization
jupyter lab --no-browser --ip 127.0.0.1 --port 8888

# 2) Raspberry Pi
tmux new -s tunel
ssh -N -L localhost:8888:localhost:8888 aluno_marcos_IC@guilherme-Xeon

# 3) Laptop (deixar aberto)
ssh -N -L 8888:localhost:8888 usuario@raspberrypi

# 4) Navegador do laptop: http://localhost:8888  (token ou senha)
```
